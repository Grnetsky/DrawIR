# DrawIR 文档

DrawIR 由三个角色组成，它们只通过 Vector IR 这一份纯数据契约协作：

```
 源文件 (DXF / VSDX / …)                                 目标 (Canvas / SVG / WebGL / PDF …)
        │                                                          ▲
        ▼                                                          │
 ┌──────────────┐      VectorDocument (纯 JSON)       ┌──────────────┐
 │   解析方      │ ─────────────────────────────────► │   渲染方      │
 │ @drawir/     │                                    │ @drawir/     │
 │ parser-*     │      ◄── 都依赖 @drawir/core ──►     │ render-*     │
 └──────────────┘                                    └──────────────┘
```

| 文档 | 读者 | 内容 |
| --- | --- | --- |
| [IR 中间描述完整教程](./ir-spec.md) | 所有人（先读这个） | 坐标系、矩阵、四种绘制项、动态颜色、包围盒、手写示例、速查表 |
| [解析方实现指南](./parser-guide.md) | 接入新文件格式的开发者 | 必须导出的 API、转换流程、坐标/曲线/块/颜色/文字/填充的处理方法、自检清单 |
| [渲染方实现指南](./renderer-guide.md) | 实现新渲染后端的开发者 | `Renderer` 接口、渲染管线、每种绘制项的实现算法、线宽与颜色语义、自检清单 |
